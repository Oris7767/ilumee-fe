## 🚀 3D Component Library

### 1. Lotus3D (Hero)
**Props:**
- `position: [x, y, z]` — 3D coordinates
- `scale: number` — Size multiplier (default 1)
- `color: string` — Petal color (default #B21267)
- `animate: boolean` — Enable rotation (default true)

**Structure:**
- 8 petals (hemisphere meshes) arranged in circle
- Golden center sphere (0.4 radius)
- 3 golden rings (0.8, 1.6, 2.4 radius) as aura
- Point light at center (magenta glow)
- Float animation: gentle up/down (-0.1 to 0.1)
- Y-axis rotation: 0.2 rad/s
- Petal breathing: sine wave scale pulse

**Material:**
- MeshTransmissionMaterial (glass-like)
- Transmission: 0.9 (highly transparent)
- Chromaticaberration: 0.05 (rainbow edge)
- Thickness: 0.5

### 2. Tool3DOrb (Tool Cards)
**Props:**
- `icon: 'soulplan' | 'humandesign' | 'numerology'`
- `color: string` — Theme color
- `scale: number` — Size (default 0.8)
- `isHovered: boolean` — Hover state

**Geometries by Tool:**
- soulplan: Octahedron (8-sided, spiritual number)
- humandesign: Icosahedron (20-sided, complex system)
- numerology: Dodecahedron (12-sided, numerology aspects)

**Structure:**
- Outer wireframe (main geometry)
- Inner glowing sphere (60% scale, pulsing)
- Particle ring (torus, 1.5 radius)
- Point light (intensity doubles on hover)

**Animation:**
- Y-axis rotation: 0.3 rad/s
- X-axis sine wave: 0.2 rad/s amplitude
- Hover scale: 1.0 → 1.2 (smooth lerp)
- Float: speed 2, intensity 0.3

### 3. Scene3DWrapper (Canvas Container)
**Features:**
- Ambient light: 0.4 intensity, ivory tint #F8EED8
- Directional light: 0.8 intensity, gold tint #E0B755
- Spotlight: top-down, magenta tint #B21267
- Environment: sunset preset (warm glow)
- DPR: [1, 2] adaptive pixel ratio
- Power preference: high-performance
- Transparent background (integrates with page)

**Performance:**
- Dynamic import with `ssr: false`
- Suspense fallback (branded loading state)
- GPU-accelerated (transform, opacity)
- No will-change (browser decides)
